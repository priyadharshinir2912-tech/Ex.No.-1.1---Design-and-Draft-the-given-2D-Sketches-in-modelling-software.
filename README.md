# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

AIM

   To sketch the given drawing with dimensions using fusion 360 tool.
   
REQUIREMENT

1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload
 
PROCEDURE

1. Open Autodesk Fusion 360 and create a new Part Design file. Select the Front view (XY
Plane) and choose Create Sketch to enter the sketching environment.
2. Similarly, draw the horizontal reference lines from the centre point towards both sides.
Create a horizontal line of 47 mm towards the left and another of 47 mm towards the right,
establishing the required reference positions for the sketch.
3. At the central region, use the Circle – Center Diameter Circle tool to draw the two required
concentric middle circles. Assign the specified diameters of Ø40 mm and Ø66 mm using the
Sketch Dimension tool.

<img width="655" height="696" alt="Screenshot 2026-11-20 161040" src="https://github.com/user-attachments/assets/43bbf7ed-0240-47ec-a54c-99c57eb178b1" />

4. Create a small circle of 6 mm radius at the required position around the central circular
feature. Use the Circular Pattern command to create a total of six equally spaced circles
around the centre.
5. Use the Trim tool to remove the unwanted portions of the patterned circles and obtain the
required central profile. Check that the remaining circular portions are properly positioned
and connected.
6. Create the required circles at the top, bottom, and left-side positions of the sketch
according to the reference drawing. Position these circles using the previously created
horizontal and vertical reference lines.
7. Draw a Ø128 mm circle and position it so that it is tangent to the top circle and the middle
circular region. Apply the required tangent relationship and use the Trim tool to remove the
unwanted portions of the large circle.
8. Between the middle circular region and the left-side circular feature, create a Ø40 mm
circle. Position it so that it is tangent to the corresponding circular features, and trim the
unwanted portion to form the required connecting curve.
9. Similarly, create the required Ø20 mm and Ø40 mm circles between the left-side and
bottom circular features. Position them accurately using the appropriate tangent
relationships and dimensions.
10. Use the Trim command to remove all the extra portions of the circles and arcs that are
not part of the required outer profile. Ensure that the remaining curves form a smooth and
continuous connection between the different circular features.
<img width="571" height="603" alt="Screenshot 2026-11-20 161052" src="https://github.com/user-attachments/assets/88e5a0c5-686b-4446-b0cd-b94838ea81c3" />

11. Check the left-side geometry carefully and apply the necessary geometric constraints,
including tangent, coincident, horizontal, and vertical constraints, wherever required. This
ensures that the sketch maintains the correct shape and relative positions.

12. Select the completed left-side geometry and use the Mirror command to create the
corresponding geometry on the right side. Use the central vertical reference line as the
mirror axis so that the two sides remain symmetrical.

13. After mirroring, use the Trim tool wherever necessary to remove any unwanted
overlapping or extra portions. Verify that all the circles, arcs, and connecting curves match
the dimensions and overall shape shown in the reference drawing.

14. Finally, inspect the complete sketch to ensure that all the required dimensions, curves,
circular features, and constraints are correctly applied and that the profile matches the given
reference drawing. After verifying the sketch, click Finish Sketch and save the completed
Fusion 360 design with the required file name.

15. After finishing the sketch switch to drawing mode to plot the sketch in ISO
standard.Thus, the given drawing is successfully created using Autodesk Fusion 360.
